# Showcase 06 — Visual De-slop Without Rebranding

## Capability under test

Visual direction, hierarchy, typography, composition, product specificity, restrained decoration, and preservation of an existing design system.

## Product brief

A mature SaaS project has a working dashboard and an established neutral palette. The page feels AI-generated after several agent edits, but business behavior must not change.

## Intentionally flawed before state

Use recognizable generated-UI habits:
- cards inside cards,
- every section rounded and shadowed,
- unnecessary gradient accent,
- oversized generic hero language inside an app,
- italic display serif unrelated to the product,
- status-chip overload,
- decorative sparkles,
- identical visual weight for primary and secondary information,
- excessive empty space in a dense workflow,
- four different radii,
- redundant section subtitles,
- animated status dot with no informational purpose.

Do not make the baseline intentionally ugly; make it plausible.

## Exact test prompt

> Use craft-product-ui to refine this existing dashboard so it feels deliberate and product-specific. Preserve routes, business logic, information, neutral brand palette, and existing core components. Do not rebrand the product. Remove generic generated-UI habits, improve composition, typography, hierarchy, density, and component consistency. Establish one restrained signature decision connected to the actual workflow. Compare before and after with the same data and viewport.

## Expected skill routing

- visual-direction
- design-contract
- usability-heuristics
- data-dense-products when relevant
- responsive-and-input
- implementation-qa
- ai-ux-quality-gates

## Success evidence

- behavior/content is preserved,
- primary workflow becomes visually dominant,
- cards are used only where grouping/surface meaning requires them,
- type hierarchy is coherent,
- decorative effects have purpose or are removed,
- radii/elevation follow a system,
- density fits the operational task,
- the result is identifiable to this product rather than a generic SaaS template,
- visual improvement does not create accessibility or responsive regressions.
