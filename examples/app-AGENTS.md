# UI/UX working instructions

For any task that designs, builds, redesigns, reviews, restyles, or fixes a user-facing interface, read and apply `.agents/skills/craft-product-ui/SKILL.md` before starting the relevant work. If that skill is installed elsewhere, resolve its installed location and read it there. If unavailable, say so and continue with the app's existing design system and explicit requirements; do not claim the skill was applied.

Use only the skill references relevant to the task. For backend-only work, skip this UI/UX workflow. For a small UI fix, inspect the affected surface, make the authorized correction, and verify that behavior without creating a full design process.

Preserve this app's architecture, design tokens, components, business rules, locale behavior, and accessibility requirements. For substantial new visual work, establish the user journey and explore materially different compositions before broad implementation. For reference-based implementation, preserve the approved composition, including image coverage and content hierarchy.

Verify the rendered result and affected interactions at relevant screen widths. Compare against the approved reference when one exists. Report mock behavior, unavailable integrations, and unverified checks honestly. Use an independent reviewer for substantial work when the host supports delegation; otherwise disclose that review was performed by the implementing agent.

An audit or critique request authorizes inspection and findings only; do not edit app files unless requested. This instruction does not grant permission to publish, deploy, or contact others.
