## Resolve conflicts

Treat aesthetic bans as heuristics. Keep an explicitly required font, palette, density or platform convention unless it creates a concrete unmet requirement, then explain the tradeoff.

Do not:
- mix multiple libraries' master design files,
- let a lookup overwrite accepted tokens,
- treat automated design detectors as usability proof,
- turn guideline examples into universal pixel rules,
- claim compliance from source inspection alone.

Use current official framework/accessibility documentation when precise technical rules matter. Never present generic target sizes, timings, spacing scales or breakpoint numbers as universally correct without context.
